# Fix The Ticket

1. Make the change on a branch, commit, and open a pull request.
2. Summon a Copilot code review on the PR.
3. Wait for the review: check whether it's back; if not, wait about 10 seconds
   and check again; keep polling until it lands.
4. Address every comment, push the fixes, re-summon the review, and repeat until
   it's clean.
5. Merge the PR.
